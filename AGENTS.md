# Agent Rules & Guidelines

## ⚠️ STRICT RULE: Never Commit Changes Directly to the `main` Branch
- **Do NOT commit any changes directly to `main`.**
- Always create or switch to a feature branch (e.g., `feature/...`, `fix/...`, `chore/...`) before running `git commit`.
- Merges to `main` must occur via Pull Requests or explicit user instructions after verification.
